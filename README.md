# DosGuard: DoS Attack Detection and Prevention

DosGuard is a  Network Security project. It simulates a web server that is configured like a default install, attacks it with three denial-of-service attacks (SYN flood, HTTP flood and Slowloris), and shows how the DosGuard defence system detects and stops each one automatically. A real-time web dashboard lets you launch attacks and watch what happens.

Everything runs inside the computer's memory. No real attack traffic is ever sent to any network.
